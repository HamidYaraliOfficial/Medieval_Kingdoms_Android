All keyboard shortcuts can be changed in **Settings → Controls** (click a binding, press the new key; if the key is
already used the two actions swap). The mouse controls are fixed. The table lists the **default** bindings.

## Mouse

| Action | Input |
|---|---|
| Select unit / building | Left-click |
| Box-select units | Left-drag |
| Add to / remove from selection | Shift + left-click, or Shift + drag |
| Move / attack / gather / build / garrison (context order) | Right-click |
| Minimap: move camera | Left-click or drag on the minimap |
| Minimap: order selected units to move | Right-click on the minimap |
| Rotate camera | Hold middle mouse button and drag |
| Zoom | Mouse wheel |
| Scroll the map | Move the cursor to a screen edge (can be switched off in Settings) |
| Place a building | Pick it in the build menu, left-click on the map (Shift keeps placing more), right-click or Esc to cancel |

## Touch screens (Android)

| Action | Gesture |
|---|---|
| Select a unit / building | Tap it |
| Order (move / attack / gather / build / repair / garrison) | With units selected, tap the target or the ground |
| Move the map | Drag with one finger |
| Box-select units | Press and hold for half a second, then drag |
| Zoom | Pinch with two fingers |
| Rotate the camera | Twist two fingers |
| Place a building | Choose it in the Build sheet; the ghost follows your finger (shown above it). Use the **✓** button to build, **⟳** to rotate, **✕** to cancel |
| Rally point | Select a production building, tap the rally button, then tap the ground |
| Control groups | Army panel: tap an empty slot 1–9 to save the selection, tap a filled slot to select it, press and hold a slot to overwrite it |
| Deselect | The **✕** button next to the selection panel |
| Minimap | Tap or drag on it to move the camera |
| Back | Android Back button: closes menus, opens the pause menu in a game |

The side rail holds the Build, Army, Technology and Kingdom buttons (the touch equivalents of F1–F4). The keyboard keys
above work too when a hardware keyboard is attached.

## Formations and stances

Formations: Line, Square, Shield wall, Wedge, Archer arc, Charge.
Stances: Aggressive, Defensive, Hold position.

## Speed

The speed buttons in the top bar (and the speed keys) switch between pause, 1×, 2× and 3×.
