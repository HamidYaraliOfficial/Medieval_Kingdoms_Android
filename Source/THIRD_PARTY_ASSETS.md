# Third-party components

Iron Crown: Medieval Kingdoms uses **no third-party game assets**. Every 3D model, texture,
sound effect and music track is generated by the game's own code at run time (procedural geometry,
procedural canvas textures, WebAudio synthesis). The icon (`assets/icons/`) was drawn for this project.
No commercial game names, characters or artwork are used.
